# Spec 模板说明

## 怎么用

1. **讨论阶段**：在 `templates/` 内复制 **`{编号}-{主题}-模板.md`** 到小组分支，按会议填空；不要在 `main` 上多人同时改同一文件（见协作指南）。
2. **定稿阶段**：将合并后的内容整理进仓库 **`spec/`** 下 **同编号、同主题** 的工作稿（如 `05-用户故事与验收标准.md`）。
3. **对比**：讲师可提供「参考 Spec」或与 `solution` 分支 diff。
